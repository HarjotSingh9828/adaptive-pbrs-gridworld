# Performance-Adaptive Potential-Based Reward Shaping for Q-Learning

## Project Overview

This research investigates Potential-Based Reward Shaping (PBRS) for tabular Q-learning in sparse-reward GridWorld environments.

The project compares different potential functions and reward-shaping strategies to study their effects on learning performance and convergence.

## Methods

1. Sparse Q-Learning
2. Fixed Manhattan-Distance PBRS
3. Adaptive Manhattan-Distance PBRS
4. Fixed Obstacle-Aware PBRS
5. Adaptive Obstacle-Aware PBRS

## Experimental Progress

Experiments have been conducted through Experiment 4, including a controlled ablation study.

- **Experiment 4:** Comparison of five Q-learning configurations in a 20 × 20 GridWorld.
- **Experiment 5:** Rotated-obstacle robustness study — planned, not yet completed.

## Evaluation

The experiments evaluate metrics such as success rate, convergence, and steps to reach the goal.
